# Core Software Engineering & Python Mastery 🛠️🐍

Welcome to the **Core Engineering** repository completed at **Holberton School**. This repository covers core software engineering foundations using **Python 3**, ranging from programming fundamentals and object-oriented design (OOP) to advanced file stream operations and exception handling.

---

## 📌 Repository Structure & Modules

| Module / Directory | Key Concepts & Topics Covered | Applied Practices |
| :--- | :--- | :--- |
| `python_fundamentals` | Basic syntax, control flow, loops, lists, and exception handling | Clean syntax, basic algorithms |
| `python_oop` | Classes, objects, attributes, methods, inheritance, polymorphism | Object-Oriented Design (OOD) |
| `python_advanced/file_handling` | File I/O operations, reading/writing streams, context managers (`with`) | Resource management, I/O parsing |

---

## 🛠️ Environment & Tooling

- **Language:** Python 3.8+
- **Linter & Style:** PEP 8 compliance (`pycodestyle`)
- **OS Environment:** Linux / WSL2
